# interactor-python-notebooks

Scratch notebooks: a SQLite example, a schema and planner sketch for a social VR platform, and a table of character polygon counts.

## Use

The SQLite notebook writes and reads the bundled example database. The schema notebook sketches the platform's tables and the interactivity nodes its planner may run. `polycount_in_games.tsv` lists the polygon counts of published game characters for comparison.

## Build and run

Open the notebooks in a notebook server. The SQLite and hello-world notebooks use a Sage kernel.
